## 来源

- 这些文件来自作者整理的 MiniMax H3 提示词创作规范（2026-11），按 MIT 许可发布。
- 官方语法三文档（`official-skill.md` / `base-en.txt` / `ref-en.txt`）**不随本仓库分发**，原因与获取方式见 `official/README.md`。

## 优先级

1. `official/` 三文档（安装时拉取）—— 官方语法权威
2. `00-workflow.md` —— 流程与装箱权威
3. `03`–`09` 创作板块 —— 只约束其声明的生效阶段

如果 `official/` 为空，先运行仓库根目录的 `scripts/fetch-official.sh`（Windows 可用 `scripts/fetch-official.ps1`）。未拉取时仍可按本地规范工作，但官方语法优先级最高，建议先补齐。

## 维护

- 修改流程时同步更新 `00-workflow.md`、`SKILL.md` 与 `assets/delivery-template.md`。
- 保持规范文件逐字稳定，避免同一规则出现两套措辞；确需澄清时写进 `SKILL.md` 的“最容易踩”或本目录的说明，不要改动原文。
- 官方文档更新后重新运行拉取脚本。
