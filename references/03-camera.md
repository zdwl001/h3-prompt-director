# 03 镜头语言

生效阶段：② 选景别/运镜；⑥ 运镜红线质检

## 1. 景别体系与叙事功能

| 景别 | 功能 | 使用时机 |
|---|---|---|
| 大全景 | 建立环境、交代空间规模 | 开场、场景转换后第一镜 |
| 全景 | 人物与空间关系 | 走位、群戏 |
| 中景 | 动作与互动 | 叙事主力景别 |
| 近景 | 情绪、反应 | 对话、情绪转折 |
| 特写 | 细节、象征、情绪爆点 | 关键道具、爆点停留 |

- **开场钩子（前 3 秒）**：首镜必须用全片最抓人的素材——动作峰值特写（落槌水花溅）、象征物特写（发间白花）、或声音先导+特写；**禁止纯空镜/纯建立开场**。建立镜头后移至第 2–3 镜，或把环境信息融入钩子镜（钩子镜背景即空间交代）（默认值，可改）。
  - **钩子必须有张力**：至少具备"动作进行中／强声音元素／视觉运动（运镜或主体运动）／悬念缺口"之一；静态无声无运动的特写**不算钩子**。钩子镜时长 ≤2.5s，揭示/转折要快（默认值，可改）。
  - **钩子动作必须有可见结果**：钩子镜用动作时，动作要给出**可见结果**（捻花→花落进掌心；落槌→水花溅起），不能只"伸手靠近"就切走；只写起始态、结果不入画＝钩子失效。
- 景别推进：情绪递进=景别逐级靠近（中→近→特）；情绪释放=拉远。**同级主体跳两级以上景别须有动机**（动作转折/遮挡物）或插过渡镜头。

## 2. 运镜选择

- 叙事默认：小幅慢速推近、跟随移动；对话戏默认固定机位（Static 也要写明）（默认值，可改）。
- 情绪爆点：慢推或固定停留；**快速运镜每段至多 1 次**（默认值，可改）。
- 运镜必须有动机（服务于揭示/跟随/强调）；无动机的装饰性运镜不合格。
- 写法红线见 01：三维度自然句、禁止 token 堆叠。
- POV 主观镜头全片至多 1 次（默认值，可改）。
- **同机位切镜限制**：同机位的内容切只允许同一主体的连续变化；禁止"无人→有人"的弹入式切镜——空镜之后下一镜必须换机位或景别，或人物以远景身影已存在于空镜中；人物入场优先画内走入（走入画框）或换机位（默认值，可改）。
- **对白朝向**：对白镜头必须写明人物朝向（面向对方／四分之三侧对镜头／过肩构图）；**禁止面向镜头说台词**（打破第四面墙的设计除外）；双人互动时机位与双方朝向必须自洽（默认值，可改）。

## 3. 轴线与方位

- 双人对话戏保持连线同侧机位；跨轴必须配过渡：中性镜头／过肩镜／运镜中途跨轴并写明。
- 群戏以当前互动双方定轴线，互动对象切换时给一次交代镜头。

## 4. 质检红线

- 无动机运镜＝不合格；无交代跨轴＝不合格；无动机景别跳级＝不合格；同机位"无人→有人"弹入＝不合格；纯空镜开场（无钩子）＝不合格。
