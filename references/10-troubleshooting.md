# 10 生成排障与重试

生效阶段：交付之后的执行期（六阶段流程之外）。生成结果不达标时，按本板块顺序诊断，再决定重试方式。

## 1. 总则

- **先诊断后动参，一次重试只改一个变量**；同时改多处将无法归因。
- 问题分三层，先定位层再动手：**接线层**（ComfyUI 连线/参数）→ **提示词层**（文字）→ **资产层**（图）。
- 每次重试记录：改了什么、结果如何；连续两次同对策无效则升一层诊断。
- **语言 A/B（已完成，结论继承）**：中文正文质量已于一个真实项目项目验证（2026-09），结论＝维持中文默认。后续项目首段**不再出双语版**；仅当用户明确要求时重测。

## 2. 故障速查表

| 症状 | 诊断顺序 | 对策 |
|---|---|---|
| 接缝明显跳变 | ① 引导源是否为上一段真实末 22 帧 ② 开场描述是否与引导状态一致 ③ 音频锚定是否开启 | 重抽尾帧／改开场描述／开音频锚定 |
| 角色变脸/服装漂移 | ① ref_image_size 是否 max ② subject_definitions 是否写明身份职责 ③ 是否存在冲突参考（两张图暗示不同服装） | 改 max／补职责声明／移除冲突参考 |
| 口型对不上 | ① 对白预算是否足（字数÷4+缓冲）② `<d>` 是否逐字 ③ 段内对白镜头是否过密 | 拉长该镜头／拆段 |
| 尾帧抽出来不能用作下段引导 | 尾段可用规则被违反（末 22 帧内快速运镜/切镜导致模糊或不稳定） | 改该段末镜收尾（保留运动、去掉快运/切镜）后重生成 |
| 画面文字乱码 | 双引号逐字规则／屏上文字过长 | 缩短屏上文字或改后期字幕 |
| 参考图几乎不起作用 | ① 标签顺序是否=连接顺序 ② 是否声明职责 | 修映射／补职责声明 |
| 动作跳脱/缺中间过程（无首无尾） | ① 分镜是否补全动作链（00② 日常真实感核对法）② 单镜是否塞了两个主动作 ③ 切点是否落在结束态 | 补衔接动作重写该段／拆镜／移切点 |
| 物体凭空出现/来源错误（如衣裳从河里捞出） | 提示词是否写明物体来源与去向（00② 物体出处） | 补出处描述重写该段 |
| 人物凭空弹入（空镜→同机位有人） | 是否违反同机位切镜限制（03§2） | 换机位/景别或改人物走入画，重写该段 |
| 开场平淡不抓人 | 首镜是否纯空镜/纯建立（03§1 开场钩子） | 重设计首镜为钩子镜，重写段 1 |
| 场景图 12 格近似同角度、未覆盖全景 | 生图提示词是否含覆盖指令（02§2） | 强化覆盖指令（列出应覆盖而未覆盖的区域）重出场景图 |
| 台词说不完／被切走 | 对白时长是否按 3 字/秒（沉稳 2.5）核算 + 起收缓冲 + 镜内动作另计（05§2） | 拉长该镜头或拆镜重写该段 |
| 物体浮空（碗/包袱等） | 物体是否有可见支撑；双手被占用时原手中物是否移置（00② 物理支撑） | 补支撑/移置动作重写该段 |
| 常备手持物浮空（拐杖/伞等） | 双手动作前是否写明手持物处置（00② 常备手持物） | 补处置动作（放下/倚靠/换臂弯）重写该段 |
| 画面/资产图出现时代不符元素（现代物件等） | ① 风格开场句是否含时代约束 ② 资产生图提示词是否含时代约束（07 时代一致性红线） | 补时代约束重写该段／重出该资产图 |
| 夜景出现成串点光/灯带/均匀发光颗粒 | 提示词是否点名光源并排除现代装饰光效（07 光源点名） | 补光源点名与排除项重写该段 |
| 钩子镜动作无结果（手伸出但没完成） | 钩子动作是否写出可见结果（03 钩子动作必须有可见结果） | 补结果动作重写钩子镜 |
| 成片出现明显安静/近乎静音段 | 该段音频是否缺失；音频锚定是否生效 | 重生成该段（下游引导片段须重抽） |
| 实测切点少于规划、时间轴漂移 | 模型未严格执行 `[Shot N] At` 时间戳（实测漂移 ±0.3–0.7s、偶有合并） | 关键台词与动作留更宽余量（05 切点执行容差）；必要时减少单段切点数 |
| 画面多出未点名的道具（茶壶/烛台/书本等） | 案面陈设是否逐个点名（00② 道具白名单） | 补点名句重写该段 |
| 同一道具出现两个实例、分不清主次 | 是否写明该道具的唯一位置与状态（00② 关键道具不得重复） | 补唯一性描述重写该段 |
| 核心动作整段缺失（如"装罐"没拍） | 核心动作是否独占镜头并写出可见结果（00②） | 补独占镜头重写该段 |
| 固定陈设被端起/移动 | 取物是否写明工具且不移动陈设（00②） | 补工具与方式重写该段 |
| 人物位置瞬移（前一秒在 A，下一秒已在 B） | ① 走位是否写在切镜后的新镜头开头（模型会吞掉）② 是否缺走位镜/过渡镜（09§1 同场景换位） | 把走位移到前一镜末尾或独占走位镜，重写该段 |
| 输出无音频 | 执行层：两个 VAE 是否加载、VAEDecodeAudio 是否接 SaveVideo | 修工作流连线 |
| 生成过慢/显存不足 | 执行层：分辨率百万像素、时长、量化模型档位 | 降分辨率／换量化档（不改提示词） |

## 3. 重试决策与级联

- **提示词层问题**：只改该段提示词、只重生成该段。
- **接线层问题**：修连线重跑，提示词一字不动。
- **级联规则（关键）**：重生成段 N 后，**段 N+1 及之后的引导片段必须从新结果重新抽取**；下游提示词通常不用改，但若新尾帧状态与原开场描述不符，须同步修订开场描述。重生成发生在中段时，先评估级联成本再动手。
- 资产层问题（图本身不合格）：回 02 资产图规范重出图，受影响的所有段全部重生成。
