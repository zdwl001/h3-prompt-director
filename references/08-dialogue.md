# 08 对白与旁白

生效阶段：① 对白保留/改旁白/删决策；② 对白镜头预算；③ 对白原子性；⑤ `<d>`/画外音措辞

## 1. 对白三去向（① 解析时逐句决策）

| 去向 | 判断标准 |
|---|---|
| 保留对白 | 推动情节或揭示人物（删了故事就不成立/人物就立不住） |
| 改旁白 | 说明性信息、时间跨度交代、内心活动的外化 |
| 删除改表演 | 重复信息、可用动作/环境表达的情绪 |

- 决策结果落入交付物「决策记录」：原文句→去向→理由（一句话）。
- **台词所指物体必须入画**：台词指到的物体（"排骨剁小块"里的排骨）必须在镜头内可见，或镜头先给该物体；否则台词失去视觉锚点，后续动作会被看成"给错了"。
- **音色统一**：发声角色（含旁白）应挂音色参考音频，同一角色全片同一条音频（02§5）；无音频参考时同一角色跨段音色会漂移。

## 2. 密度与预算

- 每段对白字数 ≤ 段时长×4 字/秒 的 **40%**（默认值，可改），余量留给动作与表演。密度口径：**角色对白**全额计入；说明性旁白按**半额**计入并登记决策记录（默认值，可改）。
- 对白镜头预算=字数÷4+1–2 秒缓冲（00②）；结束留 0.5–1 秒呼吸（05）。
- 连续对白不跨段（00③ 原子性）；一组对话尽量同段完成。

## 3. 旁白工艺

- 叙述者人格全片唯一（第三人全知／角色回忆口吻），在总览声明一次。
- 画外音固定句式与闭唇声明见 01；旁白期间画面角色嘴唇闭合。
- 旁白不重复画面已显示的信息；旁白与画面错半拍（声先或画先）制造张力（默认值，可改）。
- **旁白位置一句话决策**：整句优先单镜承载（可注"中快语速"）；仅当镜时长 < 字数÷4 时才用跨切（`<scenetrans>` 两侧+延续声明）；两种方案不并列比较，按此顺序一次决定。

## 4. 多人对话

- 镜头分配：过肩正反打为主、反应镜头插入；说话人 (Sx) 映射每段附表（01）。
- 打断与重叠：合说用 (S1,S2)；打断写 `<cutoff>`+下一镜接续声明。

## 5. 原文保真

- `<d>` 内逐字保留：方言、古语、口吃不现代化不润色（01 红线）；情绪靠 `<d>` 外 delivery 描述承载。
