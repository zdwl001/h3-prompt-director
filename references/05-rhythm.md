# 05 节奏与时长

生效阶段：② 镜头时长预算、动作链补全与三段式；③ 填充率、接缝、slack；⑤ 动作描写措辞

强制核心（动作链补全、动作三段式、单镜 1 主动作）在 00②，本板块装取舍工艺。

## 1. 衔接动作取舍粒度

- **必补**（物理必要）：换手/换姿/位移/拿起放下/视线转移——不补则下一个动作不可信。
- **可省**（观众自动脑补）：重复同类动作的过程（连捶三下写"连续捶打"不逐次列）；例行流程的中间步（已建立过的动作序列第二次出现可压缩）。
- 判断标准一句话：**"观众需要看见这个动作，才相信下一个动作吗？"** 是=补，否=省。
- 重复劳动型动作（捶打/行走/揉搓）写"持续/状态"而非逐次枚举；用声音与溅落细节表现次数感。

## 2. 时长预算细则

- 建立镜头 2–4 秒；过渡镜头 1.5–3 秒；情绪镜头 3–5 秒（含 1–2 秒停留）；对白镜头时长 ≥ 台词字数 ÷ **3 字/秒**（沉稳/情绪化表演按 **2.5 字/秒**）+ 1.5–2 秒起收缓冲；镜内台词前后还有动作的，动作时间另计——**台词必须在镜头内说完**，宁可拉长镜头或拆镜，不允许被镜头切走。
  - **逐句核算表（成文前强制，落盘交付物）**：逐句列出 字数 / 所在镜 / 该镜可用时长 / 按上式算出的需求时长；**可用 < 需求 的必须拉长镜头、跨切（两侧 `<scenetrans>`）或拆镜**；跨切时可用时长＝两侧镜头可用时间之和。禁止只按语速算而不加缓冲。
  - **切点执行容差**：模型对 `[Shot N] At` 时间戳的执行有实测漂移（±0.3–0.7s，个别切点会被合并），实际镜头常比规划短。故台词预算的余量按更宽取：对白/旁白所在镜头 ≥ 字数÷3 + **2–2.5 秒**缓冲；**关键台词不要安排在短镜头**（< 需求+0.5s）上，优先放到长镜或跨切承载。
- 对白结束后留 **0.5–1 秒呼吸**再切镜（默认值，可改）。
- 段内张弛交替：连续快切动作后接一个慢镜头呼吸（默认值，可改）；全片节奏跟随情绪曲线起伏。

## 3. 装箱节奏

- 镜头时长与切点允许毫秒小数：按帧数直算（帧÷24），不追求整秒美观，不为凑整数反复调整。
- **吸附后强制反算**：段吸附到网格值后，必须把各镜时长按"段总帧数÷24"反算出小数，**写进总览表镜头构成列**（如 5.88s 段 = 镜5 3.38s + 镜6 2.5s，合计须=5.88），镜头表与总览表两处时长必须一致，禁止总览写 5.88、镜头表写 3.5+2.5=6.0 的对不上。
- **单趟装箱算法（禁止回溯）**：按镜头顺序累加；加入下一镜将超 14.38 秒时封闭当前段；段总时长吸附最近网格值，残差按吸收顺序调整（单镜调节 ≤0.6 秒）；段内无可吸收镜头或超限时，把末镜移入下一段重新吸附；继续下一段。**一遍走完，禁止全局比较多种装箱方案**——第一个满足原子性约束的方案即最终方案。
- 高填充率（10.13–14.38 秒）优先，但**不为填充硬塞镜头**：宁可段短一格，不塞无功能镜头。
- slack 吸收顺序：过渡镜头 → 末尾氛围镜头 → 建立镜头；不动作镜头与情绪镜头。

## 4. 动作描写写法

动作描写带起始姿势与结束结果，禁止只写孤立动词短语（如"捶衣服"须写成"她直起身双手握紧木槌举过肩头，落槌捶向衣团，水花溅起，她甩了甩手腕"式完整链）。与 §1 重复动作压缩、00 动作三段式配合使用。
