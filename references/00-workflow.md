# 00 总纲与工作流程

状态：初稿待审 ｜ 适用执行端：ComfyUI 本地 Ref2VA（R2V 参考工作流）+ MiniMaxH3AddGuide 接段

## 1. 定位

- **输入**：一篇故事/小说原文。可选附加：用户指定的成片总时长、用户自备的资产图。
- **输出**：单一 Markdown 交付文件 = 总览表 + 资产表 + 整体连线图 + 逐段区块。每段区块内的提示词可直接复制进 ComfyUI 本地 R2V 工作流运行。
- **全自动**：从输入到交付不中途停下等确认；质量靠阶段⑥检查清单兜底。

### 板块挂钩表（创作板块在此接入；新增板块不改流程）

| 创作板块 | 生效阶段 |
|---|---|

| 镜头语言 | ② 选景别/运镜；⑥ 运镜红线质检 |
| 情绪表达 | ② 表演/情绪镜头预算；⑤ 表演与情绪描述措辞 |
| 节奏与时长 | ② 镜头时长预算、动作链补全与三段式；③ 填充率、接缝、slack；⑤ 动作描写措辞 |
| 声音与音乐 | ② 每镜声音设计；⑤ 音景/配乐两节 |
| 画面风格 | ② 全片风格锚点；⑤ 风格开场句 |

每个创作板块文档开头须声明其生效阶段；板块只约束其生效阶段内的创作选择，不得改动流程与语法（仲裁顺序见第 7 节）。

## 2. 六阶段流程

每阶段动手前，先检索第 1 节挂钩表中该阶段对应行的板块，再开始本阶段工作。

### ① 故事解析
提取：人物表（每人一条外貌锚点描述，供资产图与提示词复用）、场景表、情节节拍列表、对白原文、情绪曲线（起承转合标注）。
- **改编范围**：默认用户指定章节/片段；未指定时智能体自选主线情节、压缩或舍弃支线，并在总览表开头用一段话说明取舍与理由。长篇不得无说明地全量硬拆。

### ② 分镜与时长预算（shot-first）
- 故事直接拆成**镜头列表**：叙事镜头与过渡/衔接镜头（空镜、反应镜头、插入镜头）一律入列；每镜给出景别、运镜、画面内容、声音与预算时长（各类型镜头的时长预算见「05 节奏与时长」§2）：
- **动作链补全**：散文省略的衔接动作必须在分镜时显式补出。日常真实感核对法：对每对相邻主动作问"**身体要从 A 的结束态到 B 的起始态，必须经过什么？**"（换手/换姿/位移/放下或拿起物件/视线转移）；答案非空即为衔接动作，入镜头列表占预算（每个 1–2 秒，或写入同镜时间线）。
- **动作三段式**：每个主动作 = 起始态（准备/姿势）→ 执行 → 结束态（结果/反应）。切点只允许落在**结束态**或**有动机的执行中点**（如举槌最高点切镜造张力）；禁止在"无首无尾"的执行中途切走。
- **物体出处**：每次拿/用/移动物体必须写明**来源与去向**（从木盆取出衣裳→按入水中→提起拧干），来源须与前镜物体状态一致（盆里的衣裳不能从河里出现）；出处缺失时模型会自行编造错误来源。
- **物体出现不得突兀**：物体进入画面时，来源同镜可见、或镜头从来源起再跟随物体、或物体**带过程入画**（自画框上方飘落/自画框边缘进入，有可见的进入轨迹）均可；禁止的只是"画面中途无过程地突然出现"（花瓣可从画面上方飘落，但要有飘落过程，不能凭空出现在画面中间）。
- **模型常识补全必须写明**：常见动作的工具/方式必须显式写出（晾晒=用衣架/直接搭杆/夹子夹住）；**工具/道具的出现不得突兀**——镜头一开始就在画面中（手中/杆上/案上）即可，或带动作入画（从筐里取出）；禁止镜头中途无来源地冒出；**使用工具的动作本身也必须逐步写出**（取出衣架→把衣挂上衣架→把衣架挂上杆，一步不跳，禁止从"工具在画面"直接跳到"结果"）；仅登记资产表不够。
- **道具白名单（防止模型自行填充案面）**：画面中出现的每一个**可移动物体**都必须是资产表已登记或提示词已点名的道具；**案面/桌面/地面上的陈设必须逐个点名**（例："石案上只有一只陶罐与一只竹匾"），未点名的可移动物体不得出现——模型会自行往桌面上补茶壶、烛台、多余的罐、书本等。
- **关键道具不得重复**：同一件道具在画面中只应出现**一个**实例；须写明它的唯一位置与状态（如"案上立着那只敞口空罐"），否则模型会再造一个同款（两个外观相同的罐并置＝观众分不清）。
- **固定陈设的使用须写明工具与方式**：从固定陈设取物必须写清**用什么工具**、**不移动陈设本身**（"用木勺从墙根陶缸中舀出一碗米"——禁止让模型把缸端起来当容器倒）。
- **核心动作独占镜头且须有可见结果**：推动剧情的核心动作（装罐、封罐、开封、举杯等）**单独占一个镜头**，并写出**可见结果**（"罐口渐满"／"罐口蒙上红布"）；禁止把核心动作与其它动作挤在同一镜里，否则模型合并镜头时会把核心动作整段省掉。
- **走位独占镜头且不得置于切镜之后**：人物换位置（水缸→石案、树下→桌边等）必须有可见移动过程，且走位**不可写在切镜后新镜头的开头**（模型会吞掉它造成瞬移）——放在前一镜末尾或独占走位镜（细则见 09§1）。
- **镜头表须含"所在区域"字段**：每镜标注本镜发生在院中/屋内何处，装箱与质检时逐镜核对相邻镜的位置连续性。
- **状态连续性**：每个动作的结束状态（手中物/口中物/姿势/位置）必须写明，且与下一动作的起始状态**兼容**；不兼容时必须有显式过渡动作（放下/咽下/擦手/换位）。实例：说话前口腔必须空（进食/含物后先写"咽下/嚼完"再说话）；端着碗的下一动作是写字，须先写"碗搁案上"。**"说话"计为独立主动作**（吃+说必须拆镜，或吃完再说）。
- **物理支撑**：所有物体在任何时刻必须有可见支撑（手持／置于平面／容器内／穿戴）；**双手被占用时，原手中物必须先放下或移置**；需要平面的动作必须先有平面（放置点/桌面/石头）；否则物体浮空（站姿双手开包袱→端出的碗必须有手托或平面可放）。
  - **逐物点名**：每个镜头里**每一个出现的物体都要写明它的持有者或支撑面**（不能默认"她拿着"）；双手被同一动作占用时，镜头内其余物体必须逐一点名归属（例：她双手举竿敲枝时，竹匾必须先写"搁在树下石面上"或"另一手承托"）。
- **常备手持物**：角色跨镜持续持有的物件（拐杖／伞／扇／篮／包袱等）在每次需要双手的动作前，必须写明其处置（放下／倚靠／换到臂弯／交给他手），并纳入形态变化表。
- **物体形态变化必须呈现**：剧情中**发生过变化的东西**（道具状态、人物衣着/发型/配饰、环境状态等，不限道具）每次出现都必须写明**当前形态**；形态变化必须由动作呈现（引起变化的那个动作），不得跳过。
  - 段内：物体在镜 N 的使用后形态 = 镜 N+1 的使用前形态，两处都写明。
  - 跨段：物体在段 N 的结束形态 = 段 N+1 的起始形态，两处都写明（开场延续句须覆盖关键物体形态，如"碗中仍是熟面带热气"）。
  - **形态变化表**：② 产出一张形态变化表（物体 → 各次出现的形态（镜/段）→ 引起变化的动作 → **该形态对应的参考图**），只列真正发生变化的物体，使形态连续可检查。显著形态变化须有对应参考图（02§3），每段挂当段形态的参考图。
- **单镜动作密度**：一个镜头最多承载 1 个主动作（含其衔接）；出现两个主动作必须拆镜或加时长。
- **单镜动作链步数上限 3 步**：一个动作链最多三步（起始／执行／结果）；超过三步的（如"覆罐盖→蒙红布→绕绳两圈扎紧→贴红纸"＝五步）**必须拆成两镜**——模型对多步链会压缩并吞掉中段步骤。
- 镜头时长自由取值（段内切镜是时间戳切点，不受网格约束）；**只有段总时长受网格约束**。
- 用户指定总时长时，以总时长为预算压缩或扩充镜头预算。

### ③ 分段装箱
- 镜头列表按顺序装箱成段（一段 = 一次生成），段总时长吸附网格值，**目标 10.13–14.38 秒的高填充率**以减少生成次数。
- 三条原子性约束：**镜头不跨段拆**；**连续对白（一句或一组对话）不跨段拆**；装箱后每段参考槽位 ≤9/3/3。
- 参考数计数口径：段内出场角色图 + 所涉场景图 + 段内出现道具图，合计 ≤9 图；超限时拆段或把次要道具并入角色/场景描述。音色参考音频计入 3 音频上限（引导通道尾音频不占参考槽）。
- **逐段连接清单随装箱同产**：装箱时即按镜头出场逐镜核对资产、产出每段连接清单（哪张资产出现在哪些镜头），不留到⑤复核。
- **不单独做装箱表**：装箱结果直接写入镜头表的"段号/切点时间戳"列。
- 取整 slack 由过渡/衔接镜头吸收（吸收顺序与禁止项见「05 节奏与时长」§3）。
- **接段模式 B**：上一段生成结果的**末尾 22 帧**片段 → 本段 AddGuide 的 image 输入、frame_idx=0；**同时将该 22 帧对应的尾音频 → audio 输入**（需 audio_vae；开关可关）。开场描述写"延续上一段结尾的运动与声音"；交付物每段标注**拼接成片时裁掉前 22 帧**（执行端若自动裁前缀则免）。
- **尾段可用（原"尾帧稳定"）**：每段最后 22 帧（0.92 秒）必须落在**同一镜头内**（末 22 帧内不得切镜）、画面清晰可读；**不要求静止**——自然动作收尾、缓速运动均可（有运动反而利于引导衔接、不显拖沓）；仅禁止末 22 帧内的**快速运镜与切镜**（会产出模糊/不稳定帧，抽作下段引导源时质量差）。
- 接缝位置按叙事需要自由选择：动作收尾处、场景转换、换机位、叙事节拍中间均可；**“优先场景转换、换机位”不作硬性要求**，避开情绪爆点即可。模式 B 尾帧锚定保证接缝视觉连续。

### ④ 一致性资产
- 产出**资产表**（角色图 / 场景图 / 道具图 / 音色参考音频四类），生产规则与红线见「02 资产图规范」板块。
- **音色参考音频**：每个发声角色（含旁白）一条，同一角色全片用同一条（02§5）；无现成样本时在交付物中列出"待用户准备"清单（角色/时长/内容建议）。
- 资产图来源默认：智能体为每张资产图输出一条生图提示词，由用户生成后提供；用户自备图则直接登记。
- 资产表顺序即**全局连接顺序**：每段连接所需资产时一律按资产表顺序连，减少标签错位。

### ⑤ 提示词成文
按 01 语法底线的 Ref2VA 六段结构逐段成文。参考标签映射以该段连线清单为准。**开场连续性描述**（模式 B：延续上一段结尾的运动与声音）按③的接缝信息逐段写。场景图引用必须声明 12 格网格性质、道具图引用必须写明出现镜头与交互主体（句式见 01 语法底线）。动作描写措辞按「05 节奏与时长」§4 三段式写法。

### ⑥ 质检与交付
按第 6 节效率规则做内联质检：写每段时随写随核，**偏离项**标注在区块内；全部段完成后只做一次跨段检查（接缝/标签总数/时长合计/参考计数），结论落盘。交付物格式按第 4 节。

## 3. 硬规则权威（本节不再复述）

- 语法硬规则（双通道与标签编号、时长网格、参考上限、对白逐字、声明句式）权威 = 「01 语法底线」。
- 接段模式 B 与尾段可用的定义见本总纲 §2③；装箱三原子性见 §2③；资产红线见「02 资产图规范」。
- 智能体系统指令内置同款不变量作双保险；多处表述若出现分歧，仲裁顺序见第 7 节。

## 4. 交付文件结构

1. **总览表**：段号｜镜头构成（镜头号+各镜时长，含 slack 调整记录）｜段时长（网格值）｜参考槽位占用｜引导来源（首段=无/资产图，其余=上一段末 22 帧）；表头下附**全局生成参数**（分辨率/采样器/ref_image_size，全片写一次）
2. **资产表**：全局编号｜名称｜锚点描述｜生图提示词或用户提供标记
3. **整体连线图**：默认省略——逐段连接清单即操作版连线图；仅当用户明确要求时生成 mermaid 总览
4. **逐段区块**，每段含：
   - 参数：时长网格值（及帧数）；分辨率/采样器继承总览全局参数，本段有偏离才写
   - 连接清单（含说话人映射）：参考通道按顺序列出 资产→标签映射、角色→(Sx)；引导通道列出 来源片段→frame_idx（含音频锚定）
   - 提示词正文：Ref2VA 六段（subject_definitions / summary / retention_analysis / detailed_description / overall_soundscape / non_diegetic_music）
   - 拼接说明：裁前 22 帧提示（首段除外）

## 5. 质检清单（阶段⑥逐条过；文件只记偏离项与跨段检查结论，通过项不逐条落盘）

- [ ] 段时长为合法网格值，且与所有时间戳一致
- [ ] 参考标签编号 = 该段连接清单顺序，无未定义标签、无跳号
- [ ] guide 片段未被写入任何标签
- [ ] 开场描述与引导片段状态一致（运动/声音延续）
- [ ] 尾段可用：末 22 帧同镜、清晰可读、无快速运镜/切镜（**不要求静止**）
- [ ] 对白 `<d>` 逐字、`(Sx)` 段内一致且与说话人映射表相符、画外音句式正确
- [ ] 模式 B 音频锚定：尾音频与 22 帧画面同源同长（开关关闭时跳过）
- [ ] overall_soundscape 与 non_diegetic_music 两节齐备（无音乐写 N/A）
- [ ] 单段复杂度未超载（角色/切镜/对白量与时长匹配）
- [ ] 每段参考数未超 9/3/3
- [ ] 每个主动作有起始态与结束态；相邻主动作间的衔接动作已补全；无"无首无尾"切点
- [ ] 每次物体操作有来源与去向，且与前镜物体状态一致
- [ ] 入画物体出现不突兀（来源可见/镜头从来源起/带过程入画）；使用的工具出现不突兀、且使用动作逐步写出（无跳步）
- [ ] 状态连续性：前一动作结束状态（手中/口中/姿势/位置）与下一动作起始兼容，不兼容处有显式过渡
- [ ] 物理支撑：所有物体有可见支撑；双手被占用时原手中物已放下/移置；需平面的动作已有平面
- [ ] 常备手持物（拐杖/伞/篮/包袱等）在每个双手动作前已写明处置
- [ ] 台词/旁白逐句核算表已给出，每句可用时长 ≥ 字数÷3（沉稳 2.5）+1.5–2 秒缓冲（跨切按两侧之和）
- [ ] 单镜动作逐镜点数：列出每镜动作数，任一镜 >1 主动作必须拆镜；单镜动作链 ≤3 步（超则拆镜）
- [ ] 每个物体写明当前持有者/支撑面（不得默认"她拿着"）
- [ ] 内部一致性：镜头表 ↔ 提示词 ↔ 形态变化表 ↔ 资产表编号四处交叉一致，无编号撞车
- [ ] 道具白名单：镜内每个可移动物体均已在提示词中点名；案面陈设逐个点名；同一道具无重复实例
- [ ] 固定陈设取物写明工具、不移动陈设本身
- [ ] 核心动作独占镜头且写出可见结果
- [ ] 位置连续性：镜头表含"所在区域"；相邻镜换位有可见移动过程，无"切镜后已在新位置"的瞬移

## 6. 执行效率规则（速度红线）

1. **空检索跳过**：知识库检索返回空（板块尚未建立）时，**最多尝试 1 次即跳过**该板块，禁止换词重试；在交付物中注明"该板块规范缺位，按官方语法与总纲执行"。
2. **一次读入+懒加载**：开工时只读 00、01、02 各一次；创作板块（03–09）**到其生效阶段开始前才读**（按挂钩表），读过即引用，禁止开工全量预读、禁止重复检索或重读已读文档。
3. **增量交付**：交付物必须用文件工具**分步写入**——先写总览表+资产表+连线图骨架，再**逐段追加**段区块（一次工具调用写一段）；聊天回复只含简短进度说明与最终摘要+文件路径。**禁止把完整交付物塞进单条聊天消息**。
4. **内联质检**：写每段区块时随写随核第 5 节清单中该段相关项，结果标注在区块内；完成后只做一次跨段检查。禁止全文重读式复检。
5. **紧凑中间产物**：①–④ 阶段产物只以表格形式落入交付物文件（人物表/场景表/镜头表/装箱表/资产表）；禁止在聊天中写叙述性过程散文。
6. **单段输出预算**：单段区块（含六段提示词）控制在必要信息内，subject_definitions 只定义该段实际使用的标签，不复制全片资产表。
7. **阶段隔离思考，想完即写**：每个思考块只处理一个阶段，且必须以写文件等工具调用结束；**收到故事后的第一个思考块只允许做一件事：创建交付物文件骨架（总览表占位）**，建文件之前禁止任何深度规划；发现当前思考已越入下一阶段内容时，立即停止思考、先写当前阶段产物再继续。**②③ 允许共用思考块**：按 ≤6 镜一批，"设计+装箱+该批连接清单"一趟完成、每批写完即落盘。⑤ 写某段前只思考该段，禁止一次性预想所有段的提示词。
8. **思考纪律**：禁止在思考中复述规范条文（规范已读入，直接应用）；禁止列多个候选方案对比权衡（装箱按 05§3 单趟算法一次走完；其余决策按规范默认值一次决定，理由一句话记入表格）；算术每段只做一次，结果直接写表；工具 schema 已就绪、直接调用，禁止花思考确认 ToolSearch 或 schema 加载问题。
9. **分批规划（段数总量不设上限）**：故事有多少段，交付物就覆盖多少段，**内容完整性优先**。安全阀装在思考块粒度上：① 按章节/情节块分析、逐块写表；② 每批 ≤6 镜设计并追加镜头表；③ 按 05§3 单趟算法边走边写装箱表行。成片 >12 段时交付物可按情节部分拆成多文件（上/中/下）便于管理，部分间接片连续性按模式 B 衔接（上部分末段尾帧供下部分首段引导），总览注明分册结构。
10. **失败自救**：若中途报错/截断，恢复时先读交付物文件已写入的部分，**从最后一个成功段区块续写**；禁止从头重跑全流程。
11. **自动检查点**：阶段④完成（计划表全部落盘）后**结束当前回合**，用一行摘要收尾（段数/总时长/资产数/文件路径）；用户回复"继续"后进入⑤⑥，按规则 3/7 逐段增量写完。长思考任务切成两个回合是当前模型下避免接口截断的硬约束。
12. **决策落盘**：任何偏离默认值的取舍决策（旁白位置、密度超限批准、资产并入/免图、接缝选择等）在做出的当下写入交付物「决策记录」表（决策/理由/阶段）；崩溃恢复时先读决策记录与已写区块，**按记录执行，已决事项禁止重新权衡**。

## 7. 冲突仲裁与开关

- 仲裁顺序：**官方语法三文档（库内原文）＞ 本总纲 ＞ 各创作板块规范**。创作板块不得违反官方硬约束。
- 开关（可按项目临时改）：接段模式 A 单帧 / B 末22帧片段（默认 B）；B 的音频锚定（默认开）；资产图来源（默认智能体出生图提示词）；总时长（默认随故事自然）；改编范围（默认用户指定，未指定时智能体选主线）；**正文语言（默认中文，可切回官方英文）**。
